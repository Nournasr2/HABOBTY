# Just For You ❤️

A polished romantic mini-game made with vanilla HTML, CSS and JavaScript.

## Files
- `index.html`
- `style.css`
- `script.js`

## Run locally
Open `index.html`.

## GitHub Pages
Upload the files to a repository, then:
Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.

No build tools or server are required.
